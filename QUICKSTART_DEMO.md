# 🚀 QUICK START — Демонстрация в 15 минут

## ✅ Предварительные условия

```bash
# Убедитесь, что установлены зависимости и БД инициализирована:
cd /workspaces/termovision
npm install                   # Если еще не установлены
npm run import-all           # Импортировать данные сети
node server/scripts/seed-demo.js  # Загрузить demo данные
npm start                    # Запустить сервер на порту 4000
```

**Если сервер уже запущен, пропустите выше и переходите к демо.**

## 🌐 СЦЕНАРИЙ 4: Offline Режим (2 минуты)

### 1. В мобильном приложении откройте задание

Приложение перейдет в режим без интернета.

### 3. Завершите осмотр (как в сценарии 3)

### 4. Видите сообщение:
```
⚠️ Вы в режиме OFFLINE
📱 Данные сохранены локально
⏳ Синхронизируются при подключении
```

### 5. Включите интернет (снимите галочку "Offline")

### 6. Видите:
```
🟢 ONLINE
✅ Синхронизация...
✓ Осмотр BMA92 загружен на сервер
✓ 2 дефекта добавлены
```

**Говорить:** "Система работает полностью offline. Все данные сохраняются локально и синхронизируются автоматически. Идеально для полей без сигнала."

## 🎯 ТЕХНИЧЕСКИЕ ДЕМО КОМАНДЫ

Если нужно показать API прямо в терминале:

### Проверить Dashboard KPI
```bash
curl -s http://localhost:4000/api/dashboard | jq '.kpis'
```

### Получить карту (GeoJSON)
```bash
curl -s http://localhost:4000/api/map | jq '.nodes.features | length'
```

### Получить риск-оценку
```bash
curl -s "http://localhost:4000/api/analytics/risk?limit=5" | jq '.[0]'
```

### Получить мобильные задания
```bash
curl -s http://localhost:4000/api/mobile/tasks | jq '.'
```

## 🎬 СЦЕНАРИЙ: "АВАРИЙНЫЙ РЕМОНТ" (7 минут)

Показывает полный cycle от обнаружения до завершения:

1. **Диспетчер в офисе:**
   - Видит на Dashboard: +1 новая авария
   - Открывает Map, видит красный узел TK20-13
   - Кликает "Simulate outage" → видит 280 человек без отопления
   
2. **Диспетчер создает работу:**
   - "Создать ремонт" → выбрать район, описание, приоритет
   
3. **Бригада в поле:**
   - На планшете видит новое задание
   - GPS показывает локацию: 100м от текущего положения
   - Приезжает, выполняет осмотр
   - Фото, дефект, результаты
   - Сохраняет даже если нет сети
   
4. **Синхронизация:**
   - Вернулась в офис
   - Автоматическая синхронизация
   - Диспетчер видит результаты в истории
   
5. **Завершение:**
   - Работа отмечена как выполнена
   - На Dashboard обновляется статистика
